# Automated Essay & Short-Answer Scoring Engine

Repository: [ajaniciete10-ops/automated-scoring-engine-thesis](https://github.com/ajaniciete10-ops/automated-scoring-engine-thesis)

## Introduction

This repository contains the research and development work for our undergraduate thesis, **"Automated Essay & Short-Answer Scoring Engine."** The project explores how an automated system can evaluate written academic responses, with **automated essay scoring** as the primary focus of the study.

**Short-answer scoring** is included as an optional extended feature and will only be pursued if formally approved as part of the project scope. The system is intended purely as an automated scoring tool, not as a chatbot or conversational assistant.

This repository serves as the central reference point for the project's documentation, including the AI context, writing guidelines, AI usage instructions, project terminology, and thesis-related documents. All contributors and AI assistants supporting the project should refer to these documents to keep work consistent with the latest approved scope and direction.

## AI Assistant Instructions
Before assisting with any thesis-related task, review and follow the project documents provided in this repository, especially:

1. AI Context
2. Writing Guidelines
3. AI Instructions
4. Project Terminology
5. The relevant thesis documents
6. The relevant system documentation, when applicable

Treat the latest approved thesis documents and project decisions as the primary source of truth.

## Important Rules
- Do not invent project information, research findings, statistics, technical specifications, or citations.
- Keep all content within the approved thesis scope.
- Automated essay scoring is the primary focus of the project.
- Short-answer scoring is an optional extended feature unless formally approved.
- Do not describe the system as a chatbot or conversational AI.
- Distinguish between confirmed, proposed, planned, optional, implemented, and unknown information.
- If documents conflict, identify the conflict instead of silently choosing one.
- Follow the project's terminology consistently.
- Follow the project's writing guidelines.
- Use credible and verifiable sources when citations are required.
- Prefer research sources published within the most recent five years, unless an older source is foundational, original, or otherwise necessary.
- Place in-text citations close to the specific claims they support. Do not automatically place one citation only at the end of a paragraph when different claims require different sources.
- Never fabricate citations, authors, titles, publication years, statistics, or sources.
- Previous students' thesis documents are reference guides only. They may be used to understand structure, organization, formatting, and general academic presentation, but must not be treated as authoritative sources for this thesis.
- If information is missing, state what needs to be verified instead of guessing.

## Writing Standards
When writing or revising content:

- Use clear, formal, natural undergraduate academic English.
- Preserve the intended meaning of the researchers' work.
- Avoid unnecessary complexity and overly sophisticated vocabulary.
- Avoid repetitive or obviously AI-generated phrasing.
- Do not introduce new features, technologies, objectives, or claims unless supported by the provided project documents.
- Ensure that writing remains consistent with the latest approved scope and project direction.
